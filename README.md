# Antreyart Premium

A premium luxury ecommerce experience for Antreyart, combining art, stationery, storytelling, and immersive web technology.

## Vision

To create an Awwwards-inspired online store with:

- 3D Product Experiences
- Smooth Cinematic Scrolling
- Liquid Glass UI Effects
- Premium Animations
- Interactive Product Storytelling
- Mobile-First Design
- Modern Ecommerce Features

## Planned Technology Stack

- Next.js
- React
- Tailwind CSS
- GSAP
- Framer Motion
- React Three Fiber
- Three.js
- Lenis Smooth Scroll
